## 17. BUG CHI TIẾT

### B1 — CRITICAL — `siro new` lộ secret production
- **Steps**: chạy `php siro new demo` trong project có `.env` thật.
- **Expected**: project mới không chứa secret; chỉ có `.env.example`.
- **Actual**: `demo/.env` chứa `DB_PASSWORD`, `DB_HOST`, `APP_KEY` của máy nguồn. Ngoài ra còn copy `debug_trace.php`, `debug_upload.php`, `phpunit_debug.log`, `.next`, `_ide_helper.php`, `siro-completion.*`, `storage/tests/*.db`.
- **Root cause**: `.env` không nằm trong `$exclude` của `copySkeleton()` (`NewCommand.php:143`); đoạn ghi đè `.env` từ `.env.example` (`NewCommand.php:96`) bị bỏ qua vì điều kiện `!is_file($envPath)` đã true (file vừa được copy).
- **Fix**: thêm `.env`, `.env.*`, `debug_*.php`, `phpunit_debug.log`, `.next`, `_ide_helper.php`, `siro-completion.*`, `storage/tests` vào `$exclude`; luôn sinh `.env` từ `.env.example` (ghi đè không điều kiện).

### B2 — HIGH — `benchmark --json` không phải JSON hợp lệ
- **Steps**: `php siro benchmark --iterations=20 --json` → pipe vào `jq`/`json_decode`.
- **Expected**: stdout chỉ chứa JSON.
- **Actual**: banner + "Running warmup..." in trước JSON → parse lỗi.
- **Root cause**: banner in không điều kiện trong `run()` (`BenchmarkCommand.php:28-32`).
- **Fix**: chỉ in banner khi `!$jsonOutput`; hoặc xuất JSON ra stdout sạch.

### B3 — HIGH — `benchmark --iterations=0` crash DivisionByZeroError
- **Steps**: `php siro benchmark --iterations=0`.
- **Expected**: lỗi thân thiện "iterations must be >= 1".
- **Actual**: `Fatal error: DivisionByZeroError` + stack trace thô, EXIT 255. `--iterations=abc` → `(int) 0` → crash tương tự.
- **Root cause**: không validate; `(int)` cast biến chuỗi lạ thành 0.
- **Fix**: validate `$iterations >= 1`, `$warmup >= 0` trước khi chạy; trả EXIT 1 kèm message.

### B4 — HIGH — `config:cache` thành công giả khi ghi thất bại
- **Steps**: làm `storage/framework/config.php` read-only, chạy `config:cache`.
- **Expected**: báo lỗi, EXIT != 0.
- **Actual**: Warning thô `file_put_contents: Permission denied` + vẫn in "Config cached successfully!" + EXIT 0.
- **Root cause**: không kiểm tra kết quả `file_put_contents`.
- **Fix**: kiểm tra kết quả ghi; in lỗi rõ và trả EXIT 1.

### B5 — HIGH — đường deprecation chết `db:why --explain`
- **Steps**: `php siro db:explain --query="SELECT..."` → in "Use `php siro db:why --explain`". Chạy lệnh đó.
- **Expected**: chạy EXPLAIN.
- **Actual**: `db:why` coi `--explain` là query hash → "Query not found. Hash: --explain".
- **Root cause**: `db:why` không có flag `--explain`; chỉ nhận `<query_hash>` hoặc `--slow`.
- **Fix**: hoặc implement `--explain --query=` trong `db:why`, hoặc đổi hint deprecation sang đường đúng.

### B6 — CRITICAL — `make:crud --simple` sinh code hỏng
- **Steps**: `php siro make:crud X --simple` → mở controller.
- **Expected**: controller dùng được ngay (không reference class thiếu).
- **Actual**: controller `use App\Resources\XResource` + gọi `XResource::make/collection` nhưng simple mode KHÔNG sinh file Resource → `Fatal: Class not found` khi request.
- **Root cause**: `MakeCrudCommand.php:79-82` — Resource chỉ sinh khi `!$isSimple`, nhưng `controllerWithModel()` (line 254-264) luôn reference Resource.
- **Fix**: sinh Resource trong simple mode, hoặc dùng template controller thuần model (không dùng Resource).

### B7 — MEDIUM — Unicode sinh filename mojibake
- **Steps**: `make:model 'Đặc biệt'`.
- **Expected**: từ chối/chuẩn hoá tên ASCII.
- **Actual**: sinh `ĐặcBiệtUser.php` hiển thị thành `D?cBi?tUser.php` trên Windows; rủi ro vỡ trên filesystem ASCII/case-sensitive.
- **Root cause**: `studly()` chỉ thay `-`/`_`, không loại non-ASCII.
- **Fix**: validate tên chỉ gồm `[A-Za-z0-9_]`; báo lỗi thân thiện nếu không hợp lệ.

### B8 — CRITICAL — `schedule:run` không bao giờ chạy task
- **Steps**: tạo `routes/schedule.php` với `$schedule->command('queue:work')->everyMinute()`; chạy `php siro schedule:run`.
- **Expected**: chạy queue worker.
- **Actual**: chỉ in banner core workflow, task không chạy.
- **Root cause**: `Schedule::runCommand()` gọi `$console->run([$name, ...$args])` nhưng `Console::run()` đọc `$argv[1]` — tên rơi vào index 0 → `$command = ''` → print banner. (`Schedule.php:71`)
- **Fix**: gọi `run([0 => 'siro', 1 => $name, ...$args])` hoặc thêm param command riêng.

### B9 — HIGH — màu ANSI của Tinker hỏng
- **Steps**: `php siro tinker` rồi `exit`.
- **Expected**: màu xanh/đỏ đẹp.
- **Actual**: in chữ `\e[36m`, `\e[90m`... (literal).
- **Root cause**: `\e` chỉ được PHP hiểu trong chuỗi double-quote; TinkerCommand dùng single-quote (`'  \e[90mbye\e[0m'` ở line 66, `render()` line 139-179).
- **Fix**: đổi sang `\033[` hoặc double-quote.

### B10 — MEDIUM — `make:openapi --output` / `make:postman --output` hỏng
- **Steps**: `make:openapi --output=storage/docs/x.json` với thư mục chưa tồn tại.
- **Expected**: ghi đúng file chỉ định, tạo thư mục nếu thiếu.
- **Actual**: `--output` bị coi là thư mục, file luôn tên `openapi.json`; `make:postman --output` → Warning `Failed to open stream` + vẫn báo "generated".
- **Root cause**: `--output` dùng làm dirname (`MakeOpenApiCommand.php:121`); không tạo dir cho postman (`MakePostmanCommand.php:224`).
- **Fix**: honor đúng path (đổi tên option thành `--output-dir` hoặc tôn trọng filename); tạo dir; fail loudly khi lỗi.

### B11 — HIGH — `key:generate` đổi JWT production âm thầm
- **Steps**: chạy `php siro key:generate` trên server production.
- **Expected**: cần xác nhận hoặc `--force` (APP_ENV != local).
- **Actual**: ghi đè `JWT_SECRET` ngay lập tức → mọi token cũ vô hiệu, khoá người dùng.
- **Root cause**: không kiểm tra APP_ENV, không confirm.
- **Fix**: yêu cầu `--force` khi `APP_ENV` khác `local`/`testing` (giống Laravel `key:generate --force`).

### B12 — MEDIUM — `make:migration` hardcode `table_name`
- **Steps**: `make:migration create_users_table` → xem file.
- **Expected**: tên bảng `users`.
- **Actual**: luôn `Schema::create('table_name', ...)` — không suy ra từ tên migration.
- **Root cause**: template cứng (`MakeMigrationCommand.php:46-62`).
- **Fix**: parse `create_xxx_table`/`add_xxx_to_yyy_table` để điền tên bảng, hoặc hỏi tên bảng tương tác.

### B13 — LOW — tiếng Việt lẫn trong `env:check`
- **Steps**: `php siro env:check` khi DB không kết nối.
- **Actual**: `Không thể kết nối MySQL: Database connection 'default' is not configured.`
- **Fix**: dùng tiếng Anh: `Could not connect to MySQL: ...`.
